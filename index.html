Catalog Files

📄 catalog.yaml Root manifest — includes all categories and templates
📄 components.yaml Reusable Helm component definitions
📄 repositories.yaml Helm repository sources
📄 examples.yaml Configuration examples and project templates
📄 workloads/databases.yaml Postgres, MySQL, MongoDB, DynamoDB Local
📄 workloads/cache.yaml Valkey, Memcached
📄 workloads/messaging.yaml RabbitMQ, NATS, Redpanda, ElasticMQ
📄 workloads/storage.yaml Garage (S3-compatible)
📄 workloads/devops.yaml Forgejo, Forgejo Runner
📄 workloads/devtools.yaml Mock SMTP/SMS
📄 workloads/gitops.yaml ArgoCD, Flux Operator, Flux Instance
📄 workloads/collaboration.yaml Excalidraw

CLI Commands

# List all available workloads
loko catalog list

# Search by name or tag
loko catalog search postgres

# Show workload details and available presets
loko catalog info postgres

# Install a workload into your environment
loko workload install postgres

# Install with a specific preset
loko workload install postgres --preset postgres-ui

# Sync catalog from remote (update to latest)
loko catalog sync

# Point to a custom catalog source
loko catalog use https://raw.githubusercontent.com/getloko/catalog/main/catalog.yaml
